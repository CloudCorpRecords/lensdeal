Based on the documentation for the newly released Similarweb API V5, the "Web Traffic API" is now officially classified as the Web Intelligence API. It is designed to help teams programmatically access traffic, engagement, and audience data for over 100 million websites.

Here is a comprehensive breakdown of everything the API offers, its capabilities, endpoints, and metrics.

1. Core Architecture: REST vs. Batch
Similarweb offers two distinct ways to access the data depending on your scale and speed requirements, both utilizing the same API key.

Feature	REST API	Batch API
Best For	Real-time queries, interactive apps, dashboards	Large-scale analysis, historical exports, data pipelines
Scale	1 to 50 domains per request	Up to 1 million domains per request
Metrics Available	150+ metrics	300+ metrics
Historical Data	Up to 37 months	Up to 61 months (and up to 7 years on some plans)
Response Time	Under 1 second (synchronous JSON/XML)	Asynchronous (polls a report_id and downloads as CSV)
2. API Endpoint Categories
The Web Intelligence API is divided into several endpoint categories to dissect website performance from different angles:

Website Performance: The core traffic endpoints. Provides global/country-level rankings, overall traffic and engagement, marketing channel breakdowns (Direct, Organic Search, Paid, Social, Email), geographic traffic distribution, and Similar Sites (sites with matching audience patterns).

Website Audience: Delivers insights into visitor demographics (age, gender), audience overlap between competing domains, and user interests. Unique visitors here are deduplicated across devices.

Website Content: Breaks a single website down into its structural parts to find the most popular pages, subdomains, and folders.

Website Segments: Allows you to analyze specific portions of a website (e.g., just the /blog or /checkout paths) to see traffic, marketing channels, and engagement strictly for that segment.

Referrals: Tracks incoming traffic from referring websites and outgoing traffic sent from the analyzed domain to other sites.

3. Key Metrics Available
When making a request, you can specify exactly which metrics you want returned. Core traffic metrics include:

visits: Estimated total number of visits to the website.

unique_visitors: Estimated number of individual visitors.

page_views: Estimated number of total pages viewed.

bounce_rate: Percentage of visits where the user views only one page before leaving.

average_visit_duration: Average time spent on the site per visit (in seconds).

pages_per_visit: Average number of pages viewed in a single session.

segment_share: Percentage of a site's total traffic driven by a specific segment or channel.

Estimated Revenue: E-commerce revenue estimations (available on specific endpoints).

4. Query Parameters & Capabilities
The API allows highly granular querying. Most endpoints accept the following parameters to filter your results:

Granularity: Choose between daily, weekly, or monthly data points.

Web Source: Filter traffic by device type using desktop, mobile_web, or total (combined).

Geography: Get data for over 190 countries using two-letter ISO codes (e.g., us, gb) or use ww for worldwide data. U.S. state-level data is also available.

Timeframe: Set custom start_date and end_date parameters (e.g., 2026-01 to 2026-08), or use relative keywords like latest or 3_months_ago. Month-to-date (mtd) tracking is also supported for daily granularity.

5. Pricing Structure (Data Credits)
Instead of charging per API call, Similarweb uses a Data Credit model. You only pay for the actual data points you extract.

Example Calculation: 10 Domains × 5 Metrics × 12 Months × 2 Countries = 1,200 data credits used.

Note: With V5, Similarweb has also introduced native Gen-AI and MCP (Model Context Protocol) support, meaning these endpoints are officially optimized for integration with AI agents like Claude Desktop, Copilot, and Cursor.
